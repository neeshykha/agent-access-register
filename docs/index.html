What this pass can't see
  • Runs older than the window, and runs whose transcripts Claude Code has already cleaned up.
  • Interactive sessions. The shared settings files apply to them too, so a rule no scheduled run used may still be in use by hand.
  • What a script does once it runs. A call to python3 some_script.py is one call; the files and hosts inside the script don't show up as calls.
